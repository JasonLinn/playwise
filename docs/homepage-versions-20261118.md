# 首頁版本比較與方向（2026-11-18）

## 結論

最後採用 **A 版的藍白卡片風格**，內容放入 C 整理好的真實案例、清楚的服務說明、適合對象、洗衣廠原型與 LINE 諮詢。新首頁在 `app/components/friendly/FriendlyHome.tsx`；B／C 的雜誌風元件（`app/components/studio/`）保留未刪，`app/page.tsx` 改一行即可切回。尚未上正式站。

過程：先做 C（雜誌風＋講清楚），再試「C 加回 A 的親切元素」，使用者確認想要的是「類似 A 版」，於是改用 A 的視覺重做。

| 版本 | 期間 | 優點 | 缺點 |
|---|---|---|---|
| A 藍白卡片版 | 2025-04 → 2026-10-29（commit `f105696`） | 親切好懂、LINE 諮詢按鈕明顯、頁面短 | 像模板網站、作品只有 1 個 |

| C 雜誌風＋講清楚 | 2026-11-18 測試站 | 第一眼說清楚對象與服務、右側放真實作品、3 個真實案例 | 頁面較長 |

## C 的內容

- 首屏：定位「宜蘭的網站與 LINE 系統工作室」、標題「幫民宿與小店，做網站、LINE 與自動化流程。」、三項服務清單、已上線案例。
- 首屏右側：衿日林民宿、宜蘭旅遊通、冬山河漫遊護照的真實畫面拼貼（取代原本的紅色緞帶圖）。
- 作品區：「真實案例」三張卡（宜蘭旅遊通、衿日林民宿、冬山河漫遊護照），每張標出「我們做的」；概念作品與洗衣廠 demo 放在下方。
- 澳玩客（ausbnb）暫時移除；ausbnb.com.tw 網域目前無法解析。

## 從舊版（A）加回的親切元素

- 頁首右上角綠色「LINE 諮詢」按鈕（手機版也顯示），連到 `https://lin.ee/N4ukE55`。
- 首屏說明改回口語：「我們是宜蘭的小團隊……不懂技術也沒關係」；第二顆按鈕改為「用 LINE 直接問」。
- 服務區標題改回「我們可以幫你做什麼？」，自動化與 LINE 客服的說明沿用舊版語氣與例子。
- 新增「我們最常協助的對象」三張卡（民宿／小店／創作者、一人公司／自由接案者、小型協會／社群／團隊），沿用舊版文案並附例子。
- 聯絡區加回「加入 LINE 好友」與電話。
